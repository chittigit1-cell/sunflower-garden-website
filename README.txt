OUR LITTLE UNIVERSE — SUNFLOWER BIRTHDAY WEBSITE
================================================
- index.html: cinematic home page, interactive story, memories, photobooth gallery, and birthday letter.
- sunflower-garden-background.png: the supplied garden scenery used on the home page and as the fixed background throughout the other sections.
- sunflower-garden-hero.png: previous home-page garden artwork, retained in the project.
- sunflower-garden-bg.jpg: additional garden artwork kept with the project.

Open this folder in VS Code and launch index.html with the Live Server extension.
The home page includes separate CSS sunflower heads, petals, stems, drifting particles, and falling petals.

The photobooth uses local placeholders in the images folder. To add a photo, place it there and update an image src in the photobooth section of index.html. Edit the caption in the same frame; the gallery layout stays unchanged. Select a frame to open its lightbox.

Keep the HTML and image assets in this folder. You can personalize the sample story and birthday letter and replace the existing Memories Polaroid placeholders with your own photos.
